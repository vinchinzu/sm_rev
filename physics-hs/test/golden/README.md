# Golden Tapes - Haskell Determinism

## Status: Haskell Self-Output (NOT Mini Baseline)

These JSON files are **Haskell step function output** (generated by `scripts/generate_goldens.hs`).

**NOT Mini baseline** - Haskell iteration only. Collision v1 is flat floor at Y=200.

### Files

1. **run_right.json**: Ground run, hold B+Right (0x081) for 60 frames
   - **Collision v1**: Flat infinite floor at Y=200 (checkLanding + cfgGroundY)
   - X position increases, Y stays 200 (on_ground=true)
   - Input: buttons=0x081 (B=0x001 + Right=0x080)

2. **short_hop.json**: Hold A (0x100) for 10 frames, release for 30
   - **Collision v1**: Jump squat (4 frames) → jump → rise → fall → land at Y=200
   - Peak Y < full hop
   - on_ground: true → false (jump) → true (landing)

3. **full_hop.json**: Hold A (0x100) for 40 frames, release for 20
   - **Collision v1**: Jump squat → jump → rise higher → fall → land at Y=200
   - Peak Y lower (higher on screen) than short hop
   - on_ground: true → false (jump) → true (landing)

### Wire Format: retro_rl@66836f5 12-bit SNES Mask

**FrameInput buttons** (LOCKED encoding):
```
B=0x001 Y=0x002 Select=0x004 Start=0x008
Up=0x010 Down=0x020 Left=0x040 Right=0x080
A=0x100 X=0x200 L=0x400 R=0x800
```

**Golden examples**:
- 128 = Right only (0x080)
- 129 = B+Right (0x081)
- 256 = A only (0x100)
